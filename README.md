# Система «Умное Расписание» (University Scheduler MVP)

Профессиональная система автоматизации вузовского расписания с учетом сложной доступности преподавателей, объединения потоков и гибкой фильтрации учебных планов.

## 🚀 Технологический стек

### Бэкенд
- **Язык:** Python 3.10+
- **Фреймворк:** FastAPI (асинхронный)
- **База данных:** PostgreSQL / SQLite (SQLAlchemy 2.0)
- **Парсинг:** Pandas & Openpyxl
- **Валидация:** Pydantic v2

### Фронтенд
- **Библиотека:** React 19 (Vite)
- **Стейт-менеджер:** Zustand
- **Иконки:** Lucide React
- **Стилизация:** Vanilla CSS (CSS Variables)

## 🛠 Основные модули системы

### 1. Хранилище (Data Ingestion)
Модуль для первичной загрузки данных из Excel-файлов.
- **Умный импорт:** Автоматическое объединение дубликатов. Если в файле одна и та же дисциплина указана несколько раз для разных групп, система объединит их в один **учебный поток**.
- **Дерево импорта:** Визуальное отображение загруженных файлов и статистики (количество добавленных потоков и групп).

### 2. Редактор пар (Curriculum Management)
Инструмент для тонкой настройки учебного плана перед генерацией.
- **Фильтрация по группам:** Быстрый поиск и выбор конкретной группы.
- **Управление типами:** Возможность изменить тип занятия (Лекция, Семинар и т.д.) прямо в интерфейсе.
- **Исключение из расчета:** Переключатель «В расписании / Исключена» позволяет убрать лишние дисциплины, не удаляя их из базы.

### 3. Календарь преподавателей (Availability)
Продвинутая система настройки ограничений для педагогов.
- **Режимы логики:**
  - *Черный список:* всё разрешено, кроме отмеченных слотов.
  - *Белый список:* всё запрещено, кроме разрешенных окон.
- **Типы блокировок:**
  - *Разовые:* блокировка конкретной даты.
  - *Повторяющие:* еженедельные правила (например, «занят каждый четверг на 1-й паре»).
- **Drag-and-drop:** Возможность выделять диапазоны времени мышкой.

### 4. Генерация (Launch Control)
Центр управления запуском алгоритма расписания.
- **Глобальные фильтры:** Возможность исключить типы занятий (например, «Зачеты») для всего вуза одним кликом.
- **Выбор групп:** Точечный запуск генерации только для определенных потоков.
- **Учет праздников:** Календарь исключений для праздничных дней.
- **Drill-down предпросмотр:** Проверка состава пар для каждой группы перед запуском.

## 📦 Установка и запуск

### Бэкенд
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Создайте файл `.env` на основе примера и настройте подключение к БД.
3. Запустите сервер:
   ```bash
   python src/main.py
   ```

### Фронтенд
1. Перейдите в директорию `spa`:
   ```bash
   cd spa
   ```
2. Установите пакеты:
   ```bash
   npm install
   ```
3. Запустите dev-сервер:
   ```bash
   npm run dev
   ```

## 🧬 Модель данных

- **Stream (Поток):** Основная единица планирования. Содержит название дисциплины, тип, преподавателя и список связанных групп.
- **Teacher (Преподаватель):** Хранит структурированный JSON с правилами доступности (`mode`, `specific`, `recurring`).
- **Group (Группа):** Автоматически создается при импорте потоков.
